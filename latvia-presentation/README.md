# The History of Latvia — 3-page PDF presentation

- **History_of_Latvia.pdf** — the presentation (A4 landscape, 3 pages, grid-aligned layout):
  1. Land, people and origins — hero image, facts, 8-point timeline (3000 BC → 2004), 3 photos/illustrations on a shared baseline
  2. Centuries of change: medieval Livonia, Polish–Lithuanian & Swedish rule, the Russian Empire, independence 1918, Soviet & Nazi occupations, the 1989 Singing Revolution
  3. Independence restored & Latvia today, the Song and Dance Festival, key-facts panel
- **build_pdf.py** — ReportLab script that generates the PDF (v2: fixed layout grid — all images and text blocks anchored to shared baselines/columns).

Photos from Wikimedia Commons (CC-licensed, credited on each page); illustrations AI-generated for this deck.
