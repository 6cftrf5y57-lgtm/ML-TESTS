# The History of Latvia — 3-page PDF presentation

- **History_of_Latvia.pdf** — the presentation (A4 landscape, 3 pages):
  1. Land, people and origins (with an 8-point timeline, 3000 BC → 2004)
  2. Centuries of change: medieval Livonia, Polish–Lithuanian & Swedish rule, the Russian Empire, independence 1918, Soviet & Nazi occupations, the Singing Revolution
  3. Independence restored & Latvia today, the Song and Dance Festival, key facts
- **build_pdf.py** — ReportLab script used to generate the PDF (images in `assets_opt/`, fonts in `fonts/` of the build folder).
